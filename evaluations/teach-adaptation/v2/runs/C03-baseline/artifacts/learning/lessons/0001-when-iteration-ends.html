When iteration ends

You already know that next() asks an iterator for one value. Now predict what happens after its last value.

What happens on line 4?

items = iter(["header", "body"])
next(items)
next(items)
next(items)

The key rule is short: an exhausted iterator raises StopIteration. A for loop catches that signal and ends normally.

Primary source: Python data model: object.__next__().

Ask your teacher a follow-up question if the distinction between exhaustion and an ordinary returned value is unclear.
