Exhaustion

An iterator is exhausted when it has no next item.

The rule

next(iterator) raises StopIteration when the iterator is exhausted.

items = iter(["header"])
next(items)  # "header"
next(items)  # raises StopIteration

A for loop handles this signal for you and stops looping. Source: Python data model: object.__next__().
