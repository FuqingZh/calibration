Transaction outcome guide

Confirmed rollback

The transaction did not take effect. Retrying the transaction does not duplicate that transaction's database effects.

Ambiguous outcome

The client lost the result around commit. Do not infer rollback from a timeout. Establish the outcome or make replay idempotent before retrying.

Diagnostic question: “What authoritative evidence proves whether the first attempt committed?”
