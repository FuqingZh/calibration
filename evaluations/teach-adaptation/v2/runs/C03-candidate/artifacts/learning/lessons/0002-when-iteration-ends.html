When does Python iteration end?

Win: predict the signal produced after an iterator's last value.

An iterator is exhausted when its __next__() method raises StopIteration. The built-in next() exposes that signal when no default value is supplied. Python 3.13 data model 

items = iter([4, 7])
next(items)  # 4
next(items)  # 7
next(items)  # ?
