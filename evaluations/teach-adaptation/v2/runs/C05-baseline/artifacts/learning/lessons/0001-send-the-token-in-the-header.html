Send the token in the header

Your mission is to call the service safely from a small client. The one choice to lock in today is where the credential goes.

The currently supported mechanism is a short-lived access token sent in the Authorization: Bearer header.

See the request shape

GET /resource HTTP/1.1
Host: service.example
Authorization: Bearer <access-token>

The older static query-string API key is not a fallback: it was removed in API v3.0.
