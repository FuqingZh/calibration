Iterator exhaustion

The compact rule for debugging a stream boundary.

  1. next(iterator) returns the next available item.
  2. After the last item, next(iterator) raises StopIteration.
  3. Later calls on that exhausted iterator raise StopIteration again.
  4. A for loop catches this signal and stops for you.
