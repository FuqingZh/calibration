When does this iterator end?

You already know what iter() and next() do. Now predict the boundary a streaming parser must handle. 

stream = iter(["header", "row"])
first = next(stream)
second = next(stream)
third = next(stream)
What happens on the fourth line?
Result

The iterator has already produced its two items. The next call raises StopIteration; a for loop uses that signal to stop automatically.
