Rule to keep

An iterator's __next__() returns the next item. When no items remain, it raises StopIteration; here, line 2 consumes the only item, so line 3 signals exhaustion and line 4 is not evaluated. Python 3.13 language reference

Review cue: the next time you see next(iterator), count the remaining items before predicting a value or StopIteration.
