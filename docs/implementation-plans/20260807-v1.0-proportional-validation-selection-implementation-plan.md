# Proportional Validation Selection Implementation Plan

Version: v1.0
Date: 2026-08-07
Status: complete

## Goal

Replace the unconditional complete-gate default with a proportional validation
contract. Agents should select the smallest relevant checks that can decide the
affected behavior and contracts, while preserving any repository-local rule
that explicitly requires the complete canonical gate.

## Scope

1. Add the shared principle, then update the installed global `AGENTS.md`
   template and this repository's local validation section.
2. Supersede the accepted complete-gate decision with a proportional-selection
   decision while retaining the old record for traceability.
3. Clarify that the command blocks in repository navigation describe the
   complete CI gate rather than a mandatory checklist for every local edit.
4. Update the structural contract test and add one representative docs-only
   routing case.

Do not add a validation matrix, edit unrelated skills or document types, split
the GitHub Actions workflow, or rewrite historical implementation plans.

## Verification

- inspect the final authority chain for one consistent proportional rule;
- validate the changed JSON and focused structural assertions;
- run documentation and repository checks only to the extent required by the
  affected surfaces or an explicit repository gate;
- inspect the final diff for overlap with the ongoing project-docs migration.

## Acceptance

- pure wording, navigation, or ordinary documentation changes no longer imply
  runtime tests solely because a complete repository gate exists;
- behavioral instructions, generated artifacts, executable workflows,
  compatibility surfaces, and explicit repository mandates still select the
  necessary stronger checks;
- the old quality-gate decision remains traceable as superseded history; and
- no mechanical file-type matrix is introduced.

## Result

The shared principle, installed global template, repository-local validation
entry, navigation, accepted decision, structural assertion, and one
representative docs-only routing case now carry the proportional-selection
contract. The complete CI gate remains available and unchanged.

This evidence establishes contract consistency and installer propagation. It
