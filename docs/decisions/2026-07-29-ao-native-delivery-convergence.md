# AO-Native Delivery Convergence

Date: 2026-07-29

Status: historical public summary

## Accepted Portable Result

- AO is an optional environment adapter for explicitly adopted repositories.
- Conversation authorization may start or continue a task-specific worker.
- GitHub is the pull-request, CI, review, thread, and merge fact source.
- Required checks, current-head review, and actionable-thread readback must
  match the exact current head.
- GitHub native per-pull-request auto-merge is distinct from AO project
  `autoMerge`; the latter remains disabled unless separately proven.
- Dashboard terminal access is a control surface and is off by default.

Host binaries, forks, patches, services, network addresses, hashes, backup
paths, and deployment readback were moved to private host authority. Current
public guidance lives in
[`../runbooks/agent-orchestrator-review-continuation.md`](../runbooks/agent-orchestrator-review-continuation.md).
