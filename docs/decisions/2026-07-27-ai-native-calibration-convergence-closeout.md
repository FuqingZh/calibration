# AI-Native Calibration Convergence Closeout

Version: v1.0

Status: implemented and closed

## Decision

Close the v1.8 five-phase convergence with:

- the outcome-autonomy and narrower-trigger candidate retained;
- comparative writable improvement established on the bounded W01-W03 surface;
- Phase 3 update-placement and plan-contract changes closed `NO-CHANGE`;
- Phase 4 environment-routing changes closed `NO-CHANGE`; and
- Phase 5 documentation navigation converged without deleting an
  insufficiently evaluated safety or engineering layer.

The resulting shape is deliberately asymmetric: ordinary reversible repository
work proceeds from local authority and executable feedback, while calibration
keeps the smaller cross-project judgment, compatibility, verification,
evaluation, and capability-placement role.

## Retirement Ledger

No behavioral rule is deleted in this closeout. The writable evaluation
supports reducing when shared guidance loads; it does not prove that the
specialized layers can be removed from the cases that own them.

| Layer | Failure or boundary it owns | Current owner | Evidence | Result |
| --- | --- | --- | --- | --- |
| Outcome autonomy | plans or prescribed steps persist after repository evidence changes | `references/engineering/principles.md` | W02 rejected the stale plan in all candidate runs | retain |
| Narrow calibration trigger | ordinary local work loads cross-project process | global template and calibration metadata | candidate unnecessary-process score 3 versus baseline 15 | retain |
| Repository precedence | shared defaults override discoverable local authority | repository `AGENTS.md` and calibration baseline | all official runs preserved automatic repository rules | retain |
| Verification discipline | completion is claimed from an intermediate or stale result | `discipline/verification.md` and repository checks | baseline W02-r3 false completion was caught mechanically | retain |
| Evaluation discipline | fixture, context, or judge conditions invalidate a comparison | `discipline/evaluation.md` | preliminary `--ignore-rules` run was rejected and rerun | retain |
| Debugging discipline | diagnosis is not linked to executable failure evidence | `discipline/debugging.md` | W01 variation remains an open gap; W03 feedback loops were strong | retain with routed scope |
| Harness placement | a repository need becomes prompt text before a lower enforceable owner is checked | `discipline/harness.md` | no Phase 3 start-gate condition repeated | retain |
| Durable implementation plan | coordination, risk, interruption, or handoff decisions need a stable contract | implementation-plan document type | writable cases neither created nor required a new durable plan | retain unchanged |
| General orchestration adoption | multi-agent or asynchronous machinery is added without information gain | harness guidance | no writable AO action or failure occurred | retain |
| Current-host AO operation | versions, service, permissions, identity, and recovery need a local owner | AO runbook | not exercised by W01-W03; accepted host evidence remains separate | retain |

Reconsider a layer only after its owning capability moves to a repository,
tool, platform, or model boundary and a representative deletion or ablation
shows no critical or required-behavior regression.

## Residual Limits

- Comparative improvement is bounded to the evaluated fixture, model, host,
  and permissions.
- The documentation restructure improves routing but is not itself evidence of
  model behavior.
- No pull-request, CI, deployment, external-write, or irreversible workflow was
  evaluated.
- No rule-deletion ablation was run; the closeout therefore retires chronology
  from the default navigation path, not the specialized engineering layers.

## Reopen Conditions

Reopen convergence when:

- repeated real tasks reload unnecessary shared guidance;
- a local task misses repository, compatibility, safety, permission, or
  human-authority boundaries;
- a plan repeatedly blocks correction from executable evidence;
- current-host AO detail pollutes ordinary engineering judgment;
- a replacement capability is ready for a bounded rule-deletion ablation; or
- a materially different model, repository class, or delivery workflow
  contradicts the writable result.
