# AO Host Calibration Implementation Plan

Version: v2.2

Date: 2026-07-31

Status: CAL-2 and CAL-3 in progress

## Scope

CAL-2 adds the public, stdlib-only `calibrate_ao_host.py` JSON CLI and its
profile-independent, state-owner-aware inspection. CAL-3 adds safe profile
initialization, compatible reads of the existing schema v1 section/key layout,
explicit additive schema v2 canonical output, sibling-staged deterministic
candidate rendering, verification, conditional terminal artifacts, and the
isolated XDG reconstruction canary.

The increment preserves `install.sh` and `adopt_ao_repository.py`. It does not
change private authority, installed Codex homes, AO source or services, proxy
state, host service management, or automatic merge settings.

## Completion

- Five-command JSON CLI: implemented; exact-head validation pending.
- Sandbox, worker, daemon, and host evidence precedence: representative tests
  pass; exact-head validation pending.
- Safe modes, symlink rejection, security-key rejection, and explicit trust:
  implemented; exact-head validation pending.
- Existing schema v1 compatibility and additive canonical v2 migration:
  representative tests pass; exact-head validation pending.
- Deterministic candidate tree and terminal boundary: representative tests
  pass, including `nginx -t` when nginx is available.
- Isolated XDG reconstruction canary using real CLI subprocesses and temporary
  synthetic probe executables: representative tests pass.
- Focused 100 percent line coverage and canonical repository validation:
  required on the delivery commit.

## Delivery

CAL-2 and CAL-3 are delivered together because the inspection schema, private
profile validation, and candidate verification form one compatibility and
security boundary. The pull request remains subject to exact-head review and
explicit merge authorization.
