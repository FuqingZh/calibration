# How-To Guide

## Use When

Use this type for task-oriented instructions that help a competent reader
achieve and verify one concrete outcome.

## Method Reference

Follow the [Diataxis how-to guide guidance](https://diataxis.fr/how-to-guides/).
Optimize for successful task completion rather than teaching all background
concepts.

## Local Requirements

- Place it in project `docs/how-to-guides/` when that directory is the
  project's current how-to location.
- State the goal, scope, prerequisites, versions, and assumptions.
- Give ordered, actionable steps with commands or exact interface labels where
  ambiguity would cause failure.
- Show the expected result and how to verify it.
- Link architecture, compatibility, or runbook documents when the task crosses
  those boundaries.
- State recovery or escalation guidance when a partial result can leave the
  system in a confusing or unsafe state.

## Complete When

A competent reader can perform the task from the guide and distinguish a
successful result from a partial or failed one.
