# Tutorial

## Use When

Use this type for a guided learning path that takes a reader from a known
starting state to a new capability.

## Method Reference

Follow the [Diataxis tutorial guidance](https://diataxis.fr/tutorials/). The
tutorial should teach through a coherent experience, not act as a reference
catalog or a list of unrelated tasks.

## Local Requirements

- Place it in project `docs/tutorials/` when that directory is the project's
  current tutorial location.
- State the audience, prerequisites, mission, and one tangible learning
  outcome.
- Sequence small steps that build toward the outcome.
- Use project commands, examples, and terminology from current authoritative
  sources.
- Include a verification or exercise that demonstrates the reader reached the
  outcome.
- Link external sources for claims that are not project-owned facts.
- Keep personal learner records and teaching-session notes outside team
  documentation.

## Complete When

A reader starting with the stated prerequisites can complete the path and
demonstrate the capability without hidden conversation context.
